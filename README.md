# Ironix — Official Business Website (`ironix.dev`)

> **Engineering Next-Gen Software, IoT & AI Ecosystems**

This repository hosts the official web application for **Ironix** (`ironix.dev`), built with **React**, **Vite**, and **Tailwind CSS**.

---

## 🚀 Key Features & Service Pillars

1. **Custom Software & C++ Development**: High-throughput web applications, cloud APIs, and low-latency C++ engines (featuring our HyperEngine C++ framework).
2. **IoT & Embedded Systems**: Firmware engineering, hardware microcontrollers (ESP32/STM32), MQTT edge gateways, and live telemetry dashboards.
3. **Autonomous AI & LLM Workflows**: Intelligent customer support agents, document processing pipelines, and automated multi-app integrations.
4. **CRMs, Funnels & E-Commerce**: Featuring **OmniCore** (Enterprise CRM & Omnichannel Suite) and **InvoiceNow** (Automated Invoicing & Cashflow AI).
5. **24/7 IT Support & Customer Success**: SLA-guaranteed cloud infrastructure management and dedicated technical account managers.

---

## 🛠️ Tech Stack & Architecture

- **Frontend**: React 19, Vite 6, Tailwind CSS v4, Lucide Icons
- **Deployment**: Configured for GitHub Pages via `.github/workflows/deploy.yml`
- **Domain**: `ironix.dev` (CNAME included in `public/CNAME`)

---

## 💻 Local Development Setup

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

---

## 🚀 Deployment to GitHub Pages

The repository contains a GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically builds and deploys the production bundle to GitHub Pages whenever changes are pushed to `main`.
